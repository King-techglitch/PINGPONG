# PINGPONG

A browser-based adventure Pong game built with HTML, CSS, and JavaScript.

## Features
- Classic Pong gameplay with a single-player adventure twist
- Multiple stages and boss encounters
- Power-ups and score progression
- Responsive HUD with lives, score, and stage tracking
- Start, pause, restart, and sound controls
- Best score saved in localStorage
- Mobile-friendly layout and controls

## Run locally
Open `index.html` in a browser, or serve the repo with a local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files
- `index.html` — root game entry page
- `styles.css` — styling and responsive layout
- `script.js` — gameplay logic, HUD, controls, and progression
